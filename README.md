# Luna Learns Python

一套为 8 岁孩子设计的原生 Python 互动课程。

课程不从积木式编程开始，而是让孩子直接接触真正的 Python。每节课都尽量遵循“先玩一玩，再观察，再修改，最后自己运行”的节奏，让语法和看得见的结果联系起来。

作者：**Joenix**

## 课程特点

- 左侧课程目录，可按章节和课次快速切换
- 默认打开独立的全屏课程封面；进入课程后才显示侧边栏和课程工具栏
- 课程内点击左上角小树苗品牌区，可以随时返回全屏封面
- 自动在浏览器本地保存最后学习位置，返回时可继续学习
- 每节课都是独立页面内容，适合逐步扩展
- Python 代码可以直接在浏览器中运行
- 包含按钮、输入、选择、预测和闯关等互动
- 兼容电脑与移动端，可在家庭局域网内访问
- 不需要给孩子预先安装 Python

## Python 与运行环境

- 课程语法：Python 3
- 浏览器运行器：Skulpt 1.2.0
- 兼容标记：Python 3.7-ish
- 支持当前课程使用的输出、输入、变量、条件、循环、随机数和 Turtle 绘图
- 不是完整桌面 Python 环境，不能任意安装第三方软件包
- Web：Next.js 16.2.6、React 19.2.6、TypeScript 5.9.3

练习代码和最后学习位置只保存在当前浏览器，不上传到课程服务器。清除浏览器数据或更换设备后，学习位置会重新开始。

## 本地运行

需要 Node.js `22.13.0` 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开：

```text
http://localhost:3000/
```

如果要让同一局域网内的平板或其他电脑访问：

```bash
npm run dev -- --hostname 0.0.0.0
```

然后在其他设备上访问运行电脑的局域网地址，例如：

```text
http://192.168.1.100:3000/
```

## GitHub Pages

项目支持通过 GitHub Actions 自动发布为静态网站。推送到 `main` 后，
`.github/workflows/deploy-pages.yml` 会构建并发布站点。

在线访问地址：

```text
https://luna20190312.github.io/luna-learns-python/
```

这是 GitHub Pages 的项目站点：`luna20190312.github.io` 是组织域名，
`luna-learns-python` 是当前项目名。以后其他仓库可以继续发布为
`luna20190312.github.io/新项目名/`，彼此独立。

GitHub Pages 使用 `/luna-learns-python` 子路径构建，Skulpt Python
运行时也会从该子路径加载，因此现有课程的代码运行、输入和 Turtle
绘图功能可以继续使用。

本地检查 GitHub Pages 构建：

```bash
GITHUB_PAGES=true \
NEXT_PUBLIC_BASE_PATH=/luna-learns-python \
npm run build:pages
```

## 项目结构

```text
app/
├── components/
│   ├── CourseShell.tsx       # 课程目录、路由和前后课切换
│   ├── CourseCover.tsx       # 默认封面、项目说明和继续学习入口
│   ├── LessonFrame.tsx       # 课程通用页面结构
│   └── PythonPlayground.tsx  # 浏览器内 Python 运行器
├── lessons/
│   └── LessonXX_YY.tsx       # 每节课一个独立文件
└── globals.css               # 全站与课程样式

public/runtime/                # Skulpt 浏览器 Python 运行时
```

## 新增课程约定

每次新增、删除、重命名或明显修改课程时，应在同一次改动中完成以下事项：

1. 新建或修改 `app/lessons/LessonXX_YY.tsx`。
2. 在 `app/components/CourseShell.tsx` 中登记课程。
3. 保证课程包含明确目标、可操作的互动、可运行的 Python 和简短总结。
4. 同步更新本 README 的课程目录、课程总数和完成状态。
5. 执行 `npm run build`，确认项目可以正常构建。

项目根目录的 `AGENTS.md` 也记录了这条维护规则，供后续课程生成时自动遵循。
